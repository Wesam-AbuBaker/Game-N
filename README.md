# من سيربح المليون — نسخة الطالب v3

- 14 شريحة بتصميم المعلم الأصلي.
- لا يكشف التطبيق الإجابة الصحيحة أو الخاطئة؛ اختيار الطالب يظهر بإطار سماوي هادئ وتظليل خفيف ويبقى محفوظًا أثناء جلسة التصفح.
- الشريحة الثانية: فيديو خلفية صامت يتكرر تلقائيًا، دون مشغل أو أزرار فيديو؛ طبقة الفيديو لا تعترض إيماءات اللمس. قد تمنع سياسات بعض المتصفحات التشغيل التلقائي حتى مع الكتم.
- التنقل بالسحب عند عدم التكبير، والتكبير بإصبعين، وملء شاشة العرض.
- ضع جميع الملفات في جذر مستودع GitHub Pages.
- الرجاء اختبار الشريحة الثانية على هاتف Android قبل النشر للطلاب.
